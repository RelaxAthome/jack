# RelaxAtHome

A professional, mobile-responsive static website for RelaxAtHome, ready for GitHub Pages or Cloudflare Pages.

## Deploy

1. Open **Settings → Pages** in GitHub.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.

## Update business details

Edit only `config.js` to change:

- WhatsApp number (`whatsappNumber`, digits only)
- Phone and email
- Business hours
- Service areas
- Service names and descriptions
- Session prices

The booking form opens WhatsApp with a pre-filled message. It does not save customer information in the repository or browser. HTTPS is supplied automatically by GitHub Pages.

> Replace the currently provided contact details and WhatsApp number in `config.js` before launch if needed.

All services are strictly professional and wellness-focused. No sexual services are offered.
